# 📐 Convertisseur d’unités

Longueurs, masses, températures, volumes, vitesses et octets (base 1000 ou 1024) : conversion en temps réel dans les deux sens, façon terminal.

- **Essayer** : https://mixtapps-demos.web.app/convertisseur/
- **Sur Mixtapps** : https://mixtapps.com/u/theo-garnier/bBaLcjt2WVmR1Pifh2Kj (app de démonstration du compte Théo Garnier)
- **Remixer** : sur Mixtapps, « ⚡ Remixer le code » lance l’app dans ton navigateur et un agent IA modifie
  son code ; ton remix est publié sur une branche GitHub à ton nom.

## Lancer en local

Une app statique (HTML, CSS, JavaScript, sans dépendance) : ouvre `index.html`, ou avec Node :

```bash
npm install
npm run dev
```
